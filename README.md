# Music League Companion Extension

A Chrome extension that enhances your Music League experience with additional features and functionality.

## Installation

1. **Extract the extension:**
   - Download the `ml-extension.zip` file
   - Extract it to a folder on your computer

2. **Load in Chrome:**
   - Open Chrome and go to `chrome://extensions/`
   - Enable "Developer mode" (toggle in the top right)
   - Click "Load unpacked"
   - Select the folder where you extracted the extension

The extension will now be installed and ready to use on Music League pages.

## Features

- Automatically detects Music League pages
- Provides quick access to league information
- Enhances your browsing experience with additional tools

## Development

For developers who want to modify the extension:

1. Install dependencies: `npm install`
2. Start development: `npm run dev`
3. Build for production: `npm run build`
